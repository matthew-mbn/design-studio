# Дизайн-студия — интерактивный сайт

Сайт портфолио проекта дизайн-студии. Работает как статическая страница на GitHub Pages, без backend, Node.js, сборки и сторонних зависимостей.

## Публикация

1. Откройте [Settings → Pages](https://github.com/matthew-mbn/design-studio/settings/pages).
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, каталог **/(root)** и нажмите **Save**.
4. После успешного развёртывания перейдите по адресу https://matthew-mbn.github.io/design-studio/.

## Содержимое

- Галерея двух авторских портретов.
- Калькулятор ориентировочной стоимости росписи.
- Интерактивный подбор палитры и визуальное превью.
- FAQ, навигация и мобильное меню.

Все изображения, CSS и JS включены непосредственно в `index.html`. Достаточно открыть сайт в браузере; ничего устанавливать не требуется.
